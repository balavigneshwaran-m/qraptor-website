# Description
The **ToolBar** component is used as a visual header for forms or sections. It provides a clean, styled banner area where you can display a title and optionally an icon/logo. 

This component is ideal for labeling sections clearly and consistently across your application.

# Properties

| Name             | Description                                                | Type              | Example               |
|------------------|------------------------------------------------------------|-------------------|-----------------------|
| Title            | The main text displayed in the toolbar                     | String            | "User Registration"   |
| Icon             | Optional icon or logo to display next to the title         | selection | "mdi mdi-ab-testing" |

---

# Style Options

| Name               | Description                                             | Type    | Example              |
|--------------------|---------------------------------------------------------|---------|----------------------|
| Width              | Width of the toolbar                                    | String  | 100%, 80px            |
| Height             | Height of the toolbar                                   | String  | 60px, 10%            |
| Background color   | Background color of the toolbar                         | String  | #f4f4f4, #0047ab     |
| Custom CSS class   | A custom class defined in the style editor              | String  | form-header-bar      |

---

# Usage Tips

- Use percentage-based **height** and **width** values for responsive layout.
- Customize the background color to match your form's theme or branding.
- Add an **icon** to reinforce the context of the section.
- Reuse **custom CSS classes** for consistent styling across different forms.
