# Description
The **Label** component is used to provide descriptive text for form fields, helping users understand the purpose of each input. It functions like field labels in Google Forms and enhances the usability of your form design.

This component is ideal for structuring clear and accessible forms.

# Style Options

| Name               | Description                                             | Type    | Example            |
|--------------------|---------------------------------------------------------|---------|--------------------|
| Width              | Width of the label                                      | String  | 100%, 150px        |
| Height             | Height of the label                                     | String  | auto, 40px         |
| Background color   | Background color of the label                           | String  | #ffffff, #e0e0e0   |
| Border radius      | Corner rounding for the label                           | String  | 4px, 10px          |
| Custom CSS class   | A custom class defined in the style editor              | String  | form-label-class   |

---

# Usage Tips

- Use labels consistently across all fields for better accessibility and UX.
- Adjust **width** and **height** to align labels neatly with your form layout.
- **Background color** and **border radius** can be used to make labels stand out or blend in with form themes.
- Add a **custom CSS class** if you want to reuse or centrally manage styles for labels.
