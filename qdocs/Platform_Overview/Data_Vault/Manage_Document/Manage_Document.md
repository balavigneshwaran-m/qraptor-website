# Overview

The Document Management System (DMS) allows users to organize, manage, and interact with their documents in a structured way using folders and files. It supports complete CRUD (Create, Read, Update, Delete) operations for both folders and files.

Users can preview supported document types directly in the browser or download them as needed.

You can upload files and create folders as per the **allowed file storage limit** defined in the subscription plan you have purchased. Make sure to monitor your usage to avoid reaching the storage cap.

# 3. File Preview

**You can preview the following file types directly in the browser:**
- PDF files (`.pdf`)
- Image files (`.png`, `.jpg`, `.jpeg`, `.gif`)
- Markdown files (`.md`)

**To preview a file:**
- Click on the eye icon on the file.
- A preview window will open.

**To download a file:**
- Click on the download icon on the file.
- The file will get downloaded.

![Image](/qdocs/Platform_Overview/Data_Vault/Manage_Document/document_8.png)

# 4. Delete a File

- Click on the delete icon on the file.
- An alert box will pop up asking for your confirmation.
- Click on Yes to delete the file.

![Image](/qdocs/Platform_Overview/Data_Vault/Manage_Document/document_9.png)

# 5. Delete a Folder

- Click on the delete icon on the folder.
- An alert box will pop up asking for your confirmation.
- Click on Yes to delete the folder.

>  **You cannot delete a folder if it contains any files. Please delete the files inside it first.**

# 6. Manage Document Permissions

The DMS allows granular control over document access using the **Manage Access** feature.

**Steps to Manage Permissions:**

1. **Click “Manage Access”** – Opens the permission management panel.
2. **Select the Document(s)**:
   - You can select only folders or only files at one time.
   - If you select a folder, you cannot select files simultaneously, and vice versa.
3. **Click “Manage Permission”** – Shows all available permission options.
4. **Assign or De-assign Permissions**:
   - Select users or roles to grant or remove access.
   - Permissions may include view, edit, delete, or share access rights.
5. **Handle Conflicting Permissions**:
   - If selected documents have existing permissions conflicting with the new ones, an alert will appear:

     > We found conflicting permissions. What action do you want to perform?

   - **Merge All Permissions** – Combine old and new permissions.
   - **Discard All Permissions** – Remove existing and apply only the new ones.
   - **Start from Scratch** – Clear all permissions and manually assign fresh ones.

This ensures that document access remains secure, consistent, and conflict-free.

# Best Practices

- Use clear and descriptive names for folders and files.
- Avoid uploading unsupported file types if preview is needed.
- Organize documents into logical folder structures for easier access.
- Periodically review permissions to avoid outdated access.

---

# Do’s 

- Do organize files into relevant folders.
- Do preview files to confirm correctness before downloading.
- Do delete unnecessary files to keep the system clean.
- Do regularly manage and review document permissions.

---

# Don’ts 

- Don’t upload sensitive files unless secure access is confirmed.
- Don’t delete folders unless you're sure you no longer need the files inside.
- Don’t leave documents with open permissions if sensitive.
