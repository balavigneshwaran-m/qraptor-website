# Overview

The **Audit Page** provides comprehensive monitoring and analysis capabilities for all your applications and their associated agents. This centralized dashboard allows you to track application performance, monitor agent activities, and dive deep into chat interactions and statistics.

**This feature is essential for maintaining oversight of your applications, understanding user interactions, and ensuring optimal performance across all your deployed solutions.**

This document explains how to navigate the audit page and leverage its monitoring capabilities effectively.

---

# How to Access the Audit Page

To open the **Audit Page**:

1. Log in to the portal
2. Click on the **Audit** tab from the side menu

![Image](/qdocs/Platform_Overview/Audit/Audit_1.jpg)


This will take you to the main audit dashboard where you can monitor all your applications.

---

# What You'll See on the Audit Page

## Application Overview

The main page displays a comprehensive table containing:

- **List of all applications** in a structured table format
- **Application details** including name, type, and no of agents associated with application.
- **Action buttons** for supported application types
- **Expandable rows** for each application to view detailed information
- **Agent information** associated with each application

![Image](/qdocs/Platform_Overview/Audit/Audit_2.jpg)

## Expanded Application View

When you expand any application row, you'll see:

- **Complete list of agents** associated with that application
- **Agent details** and corresponding actions

![Image](/qdocs/Platform_Overview/Audit/Audit_3.jpg)

---

# Application Types and Available Actions

## For Chatbots, Voice Bots, and WhatsApp Bots

Applications of these types will display an **Action button** that allows you to:

- Click the action button to redirect to the **/chats page**
- View all chat interactions for that specific application
- Access comprehensive chat history and analytics

## For Web Applications

Web applications will **not display the action button** as they don't support chat functionality.

![Image](/qdocs/Platform_Overview/Audit/Audit_4.jpg)

---

# Chat Monitoring and Analysis

## Accessing Chat Details

From the chats page, you can:

1. **View all chats** in a structured table format with toggle tabs (All, Live Status, History) to filter chat views.
2. **Click on any specific chat** to access detailed chat information
3. **Navigate to the chat info page** for comprehensive analysis

![Image](/qdocs/Platform_Overview/Audit/Audit_5.png)

## Chat Info Page

The chat info page provides a complete view with:

## Top Section: Chat Information
- **Identical chat details** as displayed in the chats page table
- **Quick reference** to chat metadata and basic information

## Left Section: Chat Statistics
- **Comprehensive analytics** about the conversation
- **Performance metrics** and interaction data
- **Statistical insights** into chat effectiveness

## Right Section: Monitor View
- **Interactive image/diagram** showing super agent connections
- **Clickable agent icons** for detailed exploration
- **Real-time conversation display** between user and agents with agent specific filters.
- **Complete interaction history** with timestamps
- **Message flow** and response patterns

![Image](/qdocs/Platform_Overview/Audit/Audit_6.png)
---

# Agent Execution and Monitoring

## Accessing Agent Details

You can access individual agent execution pages through two navigations:

## Method 1: From Agent Connection Visualization
1. Navigate to any chat info page
2. Locate the agent you want to monitor
3. **Click on any agent icon** within the visualization
4. This redirects you to the **agent execution page** for that specific agent

![Image](/qdocs/Platform_Overview/Audit/Audit_7.jpg)

## Method 2: From Application Expanded View
1. Expand any application in the main audit table
2. Locate the agent you want to monitor
3. **Click the view execution button** next to the agent information
4. This redirects you to the **agent execution page** for detailed monitoring

![Image](/qdocs/Platform_Overview/Audit/Audit_8.jpg)

## Agent Execution Page

The agent execution page is divided into three main sections:

## Left Section: Execution List
- **Complete list of all agent executions** in chronological order
- **Clickable execution entries** for detailed analysis
- **Execution history** with timestamps and status indicators

![Image](/qdocs/Platform_Overview/Audit/Audit_9.jpg)

## Center Section: Live Agent Flow Tracking
- **Real-time visual representation** of the selected execution's flow
- **Interactive flow diagram** showing agent processing steps
- **Live tracking** of execution progress and decision points

![Image](/qdocs/Platform_Overview/Audit/Audit_10.jpg)

## Right Section: Execution Statistics and Metadata
- **Detailed statistics** for the selected execution
- **Input and output data** with complete parameter information
- **Execution metadata** including execution time, status, tasks completion information
- **Interactive node-level statistics** click on any node within the flow tracking to view specific node inputs, outputs and other metadata.

![Image](/qdocs/Platform_Overview/Audit/Audit_11.jpg)

---

# Navigation Flow Summary

1. **Audit Page** → View all applications
2. **Expand Application** → See associated agents
3. **Action Button** (for bots) → Access chats page
4. **Select Chat** → View chat info page
5. **Agent Icons/Execution Buttons** → Access agent execution details

---

# Key Benefits

- **Centralized Monitoring**: Single dashboard for all applications and agents
- **Comprehensive Analytics**: Detailed statistics and performance metrics
- **Interactive Navigation**: Seamless flow between different monitoring levels
- **Real-time Insights**: Live conversation monitoring and agent execution tracking
- **Visual Representation**: Clear visualization of agent relationships and connections

---

# Things to Remember

- **Action buttons** are only available for chatbots, voice bots, and WhatsApp bots
- **Web applications** don't support chat functionality and won't show action buttons
- **Agent execution pages** can be accessed from multiple entry points for convenience
- **Chat statistics** provide valuable insights into user interactions and bot performance
- **Visual agent connections** help understand the flow and dependencies in your system
